One line about crypto and trading life — the strategy every trader claims, the trade every trader actually makes, and the excuse every trader tells the group chat:

> My strategy is simple: buy high, panic-sell low, then tell the group chat I was just taking profits in experience.

## Run it

```sh
node main.ts
```

It writes the single joke (114 characters, one line) to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set.
